## 🎮 소개

**Damagochi**는 당신의 코딩 활동을 추적하고 펫을 키우는 macOS 메뉴바 애플리케이션입니다.

Claude Code 및 Codex의 Hook 시스템과 통합되어, 프롬프트 입력, 툴 사용, 세션 시작 등의 개발 활동을 감지합니다. 이러한 활동들이 쌓이면서 당신의 펫이 부화하고, 레벨업하며, MBTI 기반의 고유한 성격을 형성합니다.

### 핵심 특징

- 🎨 **픽셀 아트 펫** - 80종 캐릭터의 48×48 방향별 도트 스프라이트
- 🐾 **4개 펫 슬롯** - 최대 4마리를 독립적으로 성장·장착·관리
- 📈 **공유 XP 성장** - 활동 보상을 살아 있는 모든 펫에게 결정적으로 분배
- 🧬 **80종 캐릭터** - MBTI 그룹과 희귀도 기반 부화 시스템
- 🎭 **MBTI 성격 시스템** - 코딩 패턴으로 형성되는 고유 성격
- 🔥 **스트릭 시스템** - 연속 코딩으로 XP 배율 보너스
- 🐛 **버그 잡기 미니게임** - 랜덤 등장 버그 클릭으로 XP 획득
- 🎖️ **업적 시스템** - 각종 도전 과제 완료 및 수집
- 🛠️ **장비 시스템** - 레벨업 드롭 장비로 펫 꾸미기
- 🧪 **아이템 합성** - 장착하지 않은 같은 등급 장비 10개를 다음 등급으로 합성
- ⚔️ **싱글 & 토너먼트 배틀** - 선택 펫 1:1 또는 전원 출전 순차 팀 대전
- 🌳 **다중 펫 산책** - 공원 배경에서 모든 산책 가능 펫이 함께 이동
- 📊 **통계 & 추모관** - 키워본 펫들의 기록 관리
- 🤖 **Claude Code / Codex 연동** - Hook 설치로 즉시 시작

## 🚀 설치

### Homebrew (권장)

```bash
brew tap keepbang/damagochi
brew install --cask keepbang/damagochi/damagochi
open /Applications/Damagochi.app
```

앱 실행 후 **온보딩 화면에서 Claude Code와 Codex Hook을 등록**할 수 있습니다. Codex Hook은 설치 후 Codex에서 `/hooks`를 열어 신뢰 처리를 완료해야 실행됩니다.

### 업데이트

```bash
brew update && brew upgrade --cask damagochi && osascript -e 'quit app "Damagochi"' 2>/dev/null; sleep 1 && open -a Damagochi
```

### 수동 설치 (개발자용)

요구사항: macOS 14+, Xcode 15+

```bash
git clone https://github.com/keepbang/damagochi.git
cd damagochi
make install
open /Applications/Damagochi.app
```

### 앱 삭제

```bash
brew uninstall --cask damagochi
brew untap keepbang/damagochi
```

또는 수동 삭제: `/Applications/Damagochi.app` 삭제

## 📖 사용 방법

1. **앱 실행**: `/Applications/Damagochi.app` 더블클릭
2. **Hook 등록**: 온보딩 화면에서 자동 처리
3. **코딩 시작**: Claude Code 또는 Codex를 사용하면 자동으로 펫이 성장합니다

### 메뉴바 상호작용

- 🖱️ **클릭**: 팝오버 열기/닫기
- 🔴 **빨간 점**: 잡을 수 있는 버그가 있음을 알림

### 탭별 기능

| 탭 | 설명 |
|---|---|
| 🐾 **펫** | 2×2 슬롯, 선택 펫의 상태·레벨·경험치·스트릭, 산책 버튼 |
| 🎒 **인벤토리** | 4마리 장비 요약, 선택 펫의 장착/해제·위치 조정·아이템 합성 |
| 🏆 **업적** | 달성한 업적과 진행 상황 |
| 📖 **추모관** | 지나간 펫들의 기록 |
| 🔔 **알림** | 산책 중 작업 종료 알림 목록 관리 |
| ⚔️ **배틀** | 싱글 1:1 또는 2~4마리 전원 출전 토너먼트 P2P 배틀 |
| ⚙️ **설정** | 4마리별 활동 통계·배틀 능력치, 알림, Hook 상태, 방생 등 |

## 🎮 게임 시스템

### 성장 시스템

알 단계에서 총 XP 100 달성 시 부화합니다. 부화 후에는 레벨업으로 성장합니다.

| 활동 | XP |
|------|-----|
| 프롬프트 입력 | 10 XP |
| 툴 사용 (Read, Edit 등) | 5 XP |
| 세션 시작 | 15 XP |
| 버그 잡기 | 15 ~ 300 XP |

### 펫 슬롯 & XP 분배

- 최대 4마리의 펫을 키울 수 있습니다. 종족, 레벨, HP, 성격, 장비, 인벤토리와 활동 통계는 슬롯마다 독립적입니다.
- Hook, 버그, 배틀 등 모든 XP 보상은 `egg` 또는 `alive` 상태의 펫에게 균등 분배됩니다. `dead` 펫은 제외됩니다.
- 나누어 떨어지지 않는 XP는 슬롯 순환 규칙으로 배분하므로, 총 지급 XP가 손실되지 않습니다.
- 기존 단일 펫 저장 데이터는 첫 번째 슬롯으로 자동 마이그레이션됩니다.

### 스트릭 보너스

매일 Claude Code 또는 Codex를 사용하면 스트릭이 유지되며 XP 배율이 증가합니다.

| 연속일 | XP 배율 | 마일스톤 보상 |
|--------|---------|-------------|
| 1~2일 | ×1.0 | - |
| 3~6일 | ×1.5 | - |
| 7~13일 | ×2.0 | 레어 장비 |
| 14~29일 | ×3.0 | - |
| 30일+ | ×5.0 | 레전더리 장비 |

### 캐릭터 & 희귀도

코딩 패턴에 따라 MBTI 그룹이 결정되고, 그룹 내에서 희귀도 기반으로 캐릭터가 결정됩니다.

| 희귀도 | 확률 | 연출 |
|--------|------|------|
| ⬜ 커먼 | 60% | 기본 |
| 🔵 레어 | 25% | 파란 글로우 |
| 🟡 레전더리 | 12% | 금색 글로우 |
| 🌈 미식 | 3% | 무지개 |

**MBTI 그룹별 캐릭터 (총 80종):**

| 그룹 | 커먼 | 레어 | 레전더리 | 미식 |
|------|------|------|---------|------|
| NT (분석형) | 6종 | 6종 | 4종 | 4종 |
| NF (이상형) | 6종 | 6종 | 4종 | 4종 |
| SJ (전통형) | 6종 | 6종 | 4종 | 4종 |
| SP (모험형) | 6종 | 6종 | 4종 | 4종 |

각 캐릭터의 실제 Stage 3 스프라이트, 이름·영문명·ID·희귀도, 그리고 상태/배틀/산책에서의 방향별 노출 방식은 [캐릭터 도감](./character.md)에서 확인할 수 있습니다.

### 성장 단계

| 단계 | 조건 |
|------|------|
| Stage 1 (아기) | Lv 1 ~ 10 |
| Stage 2 (성장) | Lv 11 ~ 25 |
| Stage 3 (완전체) | Lv 26+ |

### 장비 시스템

레벨업 시 장비가 드롭됩니다. 총 60종 장비 중 슬롯별로 하나씩 착용할 수 있으며, 각 펫의 인벤토리와 장착 상태는 독립적입니다. 머리·손·효과별로 구분하고 각 부위에서 높은 등급부터 정렬합니다. 아래는 대표 장비입니다.

| 슬롯 | 커먼 | 레어 | 레전더리 | 미식 |
|------|------|------|---------|------|
| 👒 **머리** | 코딩 모자, 야구 모자, 비니 | 빛나는 왕관, 마법사 모자, 사무라이 투구 | 용의 뿔, 불꽃 왕관 | 천상의 후광, 우주의 고리 |
| 🗡️ **손** | 나무 지팡이, 작은 방패, 노트북 | 마법 키보드, 수정 지팡이, 에너지 검 | 번개 마우스, 코드 스크롤 | 무한의 터미널, 시간의 모래시계 |
| ✨ **이펙트** | 작은 반짝임, 버블 이펙트, 잎사귀 흔들림 | 코드 오라, 번개 오라, 불꽃 트레일 | 무지개 궤적, 별빛 폭발 | 우주 먼지, 차원 균열 |

**드롭 확률:**

| 희귀도 | 확률 |
|--------|------|
| 커먼 | 60% |
| 레어 | 25% |
| 레전더리 | 10% |
| 미식 | 5% |

장착하지 않은 같은 희귀도 장비 10개는 다음 희귀도의 장비 1개로 합성할 수 있습니다. `common → rare → legendary → mythic` 순서이며, mythic은 최상위 등급이라 합성할 수 없습니다.

### 배틀 시스템

배틀 화면의 **이력**에서 상대, 배틀 시작 시각, 양쪽의 실제 출전 펫과 당시 레벨, 결과 및 총 승·패·무승부를 확인할 수 있습니다. 이력은 계정 단위로 저장되며 앱 재시작과 데이터 내보내기/가져오기에도 유지됩니다. 업데이트 이후 배틀부터 기록하며, 결과 없이 중단된 배틀은 승패 합계에서 제외합니다.

배틀 능력치는 각 펫의 활동 통계, 희귀도와 해당 펫이 장착한 장비로 계산됩니다. 대기·출전 선택 화면에는 선택한 펫의 현재 레벨이 표시됩니다. 저장된 레벨은 그대로 유지하되 배틀 계산과 전투 화면에만 레벨 50 상한을 적용합니다.

| 모드 | 참가 | 진행 |
|------|------|------|
| 싱글 | 선택한 alive 펫 1마리 | 기존 P2P 1:1 대결 |
| 토너먼트 | 양쪽의 alive 펫 2~4마리 | 슬롯 순서대로 출전, KO 시 다음 펫 교체, 마지막 펫 KO 시 패배 |

토너먼트의 생존 펫은 현재 HP를 다음 상대와의 대결까지 유지합니다. 전투 시작 시 외형과 장비 보정은 스냅샷으로 고정되므로 전투 중 인벤토리를 바꿔도 결과가 바뀌지 않습니다.

### 버그 잡기 미니게임

3~10분 랜덤 간격으로 버그가 등장합니다. 팝오버를 열어 클릭하면 XP 획득!

| 버그 | 확률 | XP | 제한 시간 |
|------|------|----|--------|
| 🐛 일반 | 70% | +15 | 30초 |
| 🔵 희귀 | 20% | +40 | 30초 |
| ⭐ 황금 | 9% | +100 | 30초 |
| 🌈 레인보우 | 1% | +300 | 15초 |

### 건강 & 관리

- ❤️ **체력**: 활동으로 회복, 방치 시 감소
- 😋 **배고픔**: Claude Code 또는 Codex 사용 시 증가
- 😊 **기분**: 버그 잡기, 활발한 활동으로 상승
- 💀 **사망**: 14 영업일 이상 비활동 시 발생 (기록은 추모관에 저장)
- 🕊️ **방생**: 설정 탭에서 언제든지 펫을 보내고 새 알 시작 가능

### 산책 기능

Stage 2(Lv.11) 이상의 살아 있는 펫을 맥북 화면 위에 꺼내 산책시킬 수 있습니다.

- 펫 탭에서 **산책 시키기** 버튼으로 시작
- 640×720 공원 플로팅 윈도우에서 산책 가능한 모든 펫이 함께 이동
- 이동 방향에 따라 좌/우 옆모습 스프라이트를 사용하며, Reduce Motion에서는 첫 프레임으로 고정
- Claude Code 작업 종료(2분 무활동 감지) 시 작업 내용이 말풍선으로 표시
  - 예: "작업 완료 (프롬프트 3개, 툴 7번)! 수고했어요 🎉"
  - 말풍선은 30초 후 자동 소멸, X버튼으로 즉시 닫기 가능
- 🔔 **알림 탭**에서 작업 종료 알림 목록 확인 및 삭제 가능
- ⚠️ **산책 중에는 체력 및 배고픔이 빠르게 감소하며, 체력이 0이 되면 과로사합니다**
  - 체력 100 기준으로 최대 3시간 연속 산책 가능
  - 배고픔은 약 1.5시간 만에 소진되므로 주의하세요

| 상태 | 체력 감소 | 배고픔 감소 |
|------|---------|-----------|
| 일반 | 최대 30 / 시간 (4시간 유예) | 최대 50 / 시간 |
| 산책 중 | ~33 / 시간 (3시간에 체력 소진) | ~67 / 시간 (1.5시간에 소진) |

## 🔧 문제 해결

Hook이 작동하지 않는 경우, 설정 탭에서 **Hook 제거 후 재설치**를 시도하세요.
